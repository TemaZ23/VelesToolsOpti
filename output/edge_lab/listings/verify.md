# Проверка семейства `listings` (adversarial review)

**Вердикт проверки: weakened (ослаблено).** Багов, заглядывания в будущее и занижения издержек я не нашёл. Независимая реализация повторяет цифры автора: корреляция дневных доходностей 0.997, IS Sharpe 1.59 против 1.57, OOS 1.25 против 1.20. Но весь OOS-результат сделан в 2024-01…2025-06. За последние 15 месяцев (2025-07…2026-09) Sharpe −0.22, а без октября 2025 Sharpe −1.13. Падение средней сделки статистически значимо (t = 2.45). Вывод автора edge = weak верный, но для торговли деньгами сейчас ожидаемая доходность — около нуля.

## 1. Независимая реализация

Файл: `scripts/edge_lab/verify_listings.py`. Код написан по текстовой спецификации до чтения кода автора. Использованы только `load_hourly`/`load_funding` из `common.py`.

Как устроена реализация:
- **События.** Листинг L — первый час с объёмом > 0. Релистинг — возобновление торговли после ≥ 60 дней без объёма. TradFi, индексы и переименования размечены своими списками. Итого 676 крипто-событий: 258 в IS и 418 в OOS (у автора 675).
- **Вход и выход.** Шорт по open часа L+24. Стоп: high ≥ 1.30·вход, исполнение по max(open, стоп)·1.003. Тейк: limit по 0.75·вход, считается исполненным только при low < limit, по цене лимита, комиссия мейкера. Если в одном баре задеты и стоп, и тейк, считается стоп. Иначе выход по open часа вход+168.
- **Хедж.** Лонг BTCUSDT на тот же номинал, закрывается вместе со сделкой.
- **Издержки.** Тейкер 0.05% + max(проскальзывание по ADV прошлых баров, 0.15% при возрасте 24–72 ч). Для BTC — 0.07% на сторону.
- **Фандинг.** Берутся фактические времена расчётов в барах (вход, выход]. Знак: шорт получает +rate, лонг BTC платит +rate. Номинал пересчитывается по текущей цене.
- **Портфель.** Позиция = equity/20 по переоценённому капиталу на момент входа. Переоценка почасовая, дневные доходности — по капиталу на конец суток UTC.

## 2. Чтение кода автора (`listings_data.py`, `listings_engine.py`, `listings.py`)

| Что проверял | Результат |
|---|---|
| Lookahead: сигнал и исполнение | Вход по open[L+X], а L известен заранее (листинг анонсируется). Стоп и тейк проверяются начиная с бара входа, по high/low после open. Нарушений нет |
| Фильтры и ранжирование | Нет никаких, кроме категории монеты (известна в момент листинга). Ёмкость считается по min(объём до входа, объём за удержание) — это только отчётная метрика, на сделки не влияет |
| Фандинг | Ставка бара входа исключена, бары (вход, выход] включены. Знак верный: `-q·rate·price`. Совпадает с моей реализацией |
| Survivorship и делистинг | Мёртвые бары = qvol 0 → NaN. После 24 ч без сделок выход по последнему close. Пессимистичный вариант −50% есть (у меня затрагивает 1 сделку) |
| Издержки | Обе ноги платят. Пол по возрасту 0.5% / 0.3% / 0.15% (< 6 ч / < 24 ч / < 72 ч). Стоп +0.3%. Тейк — мейкер только при пробое лимита |
| Стоп и тейк в одном баре | Считается стоп (пессимистично). У базового кандидата таких баров 0 |
| Капитал, компаундинг, двойной учёт | Позиция = equity/K на момент входа. Лимит K слотов не достигается (максимум 8 позиций при K = 20). Двойного учёта нет |
| Выбор конфигурации | Максимум IS Sharpe по 1800 конфигурациям. OOS при выборе не использовался |

**Итог: ошибок, которые меняют результат, не найдено.** Мелкие расхождения в разметке событий не влияют на результат: у меня MANTRA считается переименованием (OM→MANTRA), VIC — релистингом, ALL — индексом.

## 3. Исполнение стопов: проверка на минутках и aggTrades

Часовые свечи не показывают проскальзывание внутри бара. Поэтому проверка сделана на двух уровнях (`scripts/edge_lab/verify_listings_1m.py`):
- **1m-свечи.** Для всех 182 стопов скачаны минутные свечи за день стопа.
- **aggTrades.** Для 41 стопа в OOS (каждый третий плюс 10 самых резких) взяты реальные сделки.

Цена относительно уровня стопа (среднее / медиана / p90 / максимум):

| Метрика | Ср. | Медиана | p90 | Макс |
|---|---|---|---|---|
| Первая сделка ≥ стопа (гэп) | +0.008% | +0.006% | +0.02% | +0.03% |
| VWAP сделок за 0.2 с после срабатывания | +0.01% | 0.00% | +0.44% | +1.4% |
| VWAP за 1 с | +0.18% | 0.00% | +0.92% | +3.5% |
| VWAP за 5 с | +0.61% | +0.05% | +1.48% | +9.8% |
| Close минуты срабатывания (1m, 182 стопа) | — | −0.06% | +1.7% | +10% (p99 +6.8%) |

Заложенные +0.3% к стопу (плюс 0.15–0.4% ADV-проскальзывания) в среднем реалистичны. В худших 10% случаев стоп исполняется на 1–1.5% хуже.

## 5. Практика для счёта $1k–$20k

- **Размер позиции.** equity/20 — это $50–$1000 на сделку.
  - Минимальный ордер по альткоинам на Binance USDT-M — около $5, проблем нет.
  - **У BTCUSDT-перпа минимальный номинал около 100 USDT** (проверить MIN_NOTIONAL в exchangeInfo). Поэтому хедж BTC возможен, только если позиция ≥ $100, то есть при счёте от ~$2k при K = 20.
  - Без хеджа: OOS Sharpe 1.06, последние 15 месяцев около 0 (0.08).
  - По годам без хеджа: 2024 +20.5%, 2025 +33.3%, 2026 −0.4%.
- **Ёмкость.** 1% среднего часового объёма за 24 ч до входа: медиана $63k на сделку, p10 $6.8k (у автора, по min(до входа, удержание), $31k / $4.4k). Для счёта до $20k ограничений нет.
- **Исполнение через Veles.** Нужно вручную запускать шорт-бот на каждом листинге через 24 ч, с TP 25% и SL 30%. Выхода по времени нет, закрывать вручную через 7 дней. Новые пары могут появляться в Veles с задержкой. TP в Veles может исполняться как тейкер — это немного дороже модели.
- **Исполнение через API-скрипт** надёжнее. Схема:
  1. Опрос exchangeInfo и onboardDate раз в час; пропуск TradFi, индексов и переименований.
  2. Через 24 ч после листинга — шорт по рынку и лонг BTC.
  3. STOP_MARKET closePosition на +30%, workingType=CONTRACT_PRICE. Проверить, что priceProtect не блокирует срабатывание при расхождении mark/last.
  4. Reduce-only limit на −25%.
  5. Закрытие обеих ног через 168 ч.
- **Риски биржи:**
  - экстремальные сквизы (MYX ×240, COAI +5451%) — без стопа счёт обнуляется;
  - фандинг до −2% за час против шорта;
  - смена интервала фандинга;
  - метки Monitoring, внезапный делистинг;
  - ограничения по геолокации: API Binance с ряда IP недоступен.

## 6. Итог

- **Расчёт верный.** Ошибок, lookahead, survivorship-проблем и заниженных издержек нет. Результат воспроизводится независимо, исполнение стопов подтверждено по aggTrades.
- **Формально OOS ≥ 1 и выдерживает ±25% и издержки ×2.** Но запас хрупкий:
  - без лучшего полугодия — 0.72;
  - без 10 лучших дней — 0.71;
  - при пессимистичном исполнении стопов — 0.6–0.9;
  - доверительный интервал OOS Sharpe [0.18; 2.36].
- **Эффект значимо ослаб в последние 15 месяцев:** Sharpe −0.22, средняя сделка −0.48%, без октября 2025 Sharpe −1.13. В этот период в плюсе только 59% соседних конфигураций (±25%) и 37% всей сетки автора.
- **Вывод.** Это был реальный режимный эффект 2020–2025H1 (низкий float и высокая FDV новых листингов). Сейчас подтверждённого edge нет. Вердикт автора weak — верхняя граница. Торговать только на бумаге или минимальным размером, пока не наберётся ≥ 100 новых сделок с положительной средней.
