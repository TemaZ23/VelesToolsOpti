# Поиск рыночных неэффективностей на Binance: итоговый отчёт

Цифры портфеля взяты из output/edge_lab/combined.json (scripts/edge_lab/combine.py), цифры семейств — из output/edge_lab/<семейство>/results.json, notes.md и verify.md.

Данные: все USDT-M бессрочные фьючерсы Binance с 2020-01-01 по 2026-09-30, 900 символов, включая делистинговые.
Параметры подбирались только на IS (2020–2023). OOS (2024-01 … 2026-09) использовался только для проверки.
Все цифры посчитаны после издержек: комиссия тейкера, проскальзывание по ликвидности, фандинг с правильным знаком.

## Коротко

1. **Ни одна стратегия не прошла порог «yes» после независимой проверки.** Вердикт *weakened* («ослаблено, но не опровергнуто») получили три семейства: funding, xsec и listings. Подтверждённых (*confirmed*) нет. Семейства trend, flow и seasonality проверку не проходили.
2. **Cash-and-carry BTC+ETH — это не неэффективность, а долларовый депозит.** В OOS он дал 4.46% годовых, сверх ставки T-bill — +0.08% годовых. В 2025 и 2026 годах carry принёс меньше кэша.
3. **Комбинированный портфель MAIN: xsec 26.3% + listings 73.7%** (веса inverse-vol по IS). В OOS: Sharpe 1.65, CAGR 23.5%, max DD 18.4%, все 6 полугодий в плюсе. Формально это проходит порог, **но как прогнозу этому доверять нельзя**:
   - семейства выбраны после OOS. Если сложить IS-лучших кандидатов всех пяти рисковых семейств, не глядя на OOS, выходит OOS Sharpe 0.95 и CAGR 8.3%;
   - за последние 15 месяцев (2025-07 … 2026-09) портфель дал Sharpe 0.71 (t = 0.8) и CAGR 8.9%, рукав listings в этот период отрицательный;
   - стресс-сценарий (издержки ×2, −50% по каждой делистинговой позиции, худшее исполнение стопов) даёт OOS Sharpe 0.68, а за последние 15 месяцев −0.24.
4. **Итоговый вердикт по плану: weak.** На реальные деньги сейчас — нет. Сначала минимум 3 месяца бумажной торговли скриптом scripts/edge_lab/live_combo.py, потом решение по правилам допуска из раздела 5.
5. **Минимальный счёт для плана — около $11k при 1x.** Ниже этой суммы рукав xsec упирается в минимальные ордера Binance. На счёте $1k–5k остаётся только шорт листингов, а он за последние 15 месяцев не работает. Старт $1000 + $100/мес. по сценарию «последние 15 месяцев» через 5 лет даёт медиану $6.5k при внесённых $7k; с вероятностью 65% счёт окажется ниже взносов.

## 5. Исполнение

**Порядок действий.**

1. **Бумажная торговля ≥ 3 месяцев.** Скрипт печатает ордера и ничего не отправляет: ключей нет, только публичные эндпоинты.
   - `python3 -m scripts.edge_lab.live_combo --equity 12000 --leverage 1` — ежедневно в 00:05 UTC и ежечасно для листингов.
   - Флаг `--positions file.json` (формат {"SYMBOL": номинал USD со знаком}) печатает ордера на разницу с текущими позициями.
   - `--offline 2026-09-29` — самопроверка. Она совпадает с бэктестом: max|ΔW| = 4e-15.
   - Из нашей среды API Binance отвечает HTTP 451; скрипт выводит ошибку и выходит.
2. **Допуск к реальным деньгам — только если выполнено всё:**
   - бумажный MAIN за 3 месяца не хуже −6% (p5 базы за 6 месяцев — −5.7%);
