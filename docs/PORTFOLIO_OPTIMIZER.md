# Портфельный оптимизатор (уточнение базового бота)

Раздел «Портфельный оптимизатор» ищет более удачные значения настроек **вашего существующего бота**,
проверяя каждого кандидата **бэктестами самого Veles** на корзине монет. Кандидаты сравниваются той же
метрикой, что показывает страница «Группы бэктестов»: **P&L к риску** (P&L / максимум из МПУ и просадки).

## Чем отличается от «AI Оптимизатора»

| | AI Оптимизатор | Портфельный оптимизатор |
|---|---|---|
| Что меняет | Пересобирает бота из генома: может менять индикаторы, теряет часть условий (например, второе условие тейка) | Меняет **только числа** в копии вашего бота: пороги условий, отступы и объёмы сетки, мин. P&L тейка, отступ стопа, подтяжку. Индикаторы, ТФ, операции и все остальные поля не трогаются |
| Оценка | Сумма P&L по монетам / худший MAE % одной монеты | Портфель как в группе бэктестов: P&L, МПУ одновременных сделок, P&L к риску, + устойчивость по под-периодам |
| Экономия бэктестов | Нет | Отборочная корзина → полная только для лучших, кеш одинаковых настроек, база из готовой группы бэктестов |
| Параллельность | Один бэктест за раз | Несколько потоков (как в тарифе Veles), пауза между запусками, обработка 429 |
| Продолжение | Теряется при «Стоп» | Продолжает с места остановки, в том числе после перезагрузки страницы |

## Как пользоваться

1. **Базовый бот.** Выберите бота и нажмите «Загрузить». Таблица «Параметры» заполнится автоматически:
   все числовые настройки бота с диапазонами и шагом по умолчанию. Объём (номинальный) и сигнальные
   индикаторы по умолчанию выключены — их можно включить.
2. **Корзина монет.** Перечислите монеты (как в группе бэктестов, которой вы доверяете). Размер
   отборочной корзины — 8–12 монет: на ней проверяются все кандидаты, на полной — только лучшие.
3. **Готовые результаты базы.** Если у вас уже есть группа бэктестов базового бота на этой корзине и
   периоде — выберите её. Тогда база не будет перепроверяться (экономия десятков бэктестов).
   Период, комиссии и «фитили» должны совпадать с теми, что в форме, иначе сравнение нечестное
   (оптимизатор предупредит в журнале).
4. **Период и комиссии.** Те же, что в ваших ручных бэктестах (например, maker 0.02 / taker 0.055).
   Блокировка — как в группе бэктестов (сколько одновременных сделок учитывать).
5. **Цель.**
   - «Устойчивый P&L к риску» (рекомендуется): половина — P&L к риску за весь период, половина — худший
     под-период. Защищает от настроек, которые хороши только на одном удачном отрезке.
   - «P&L к риску как в группе» — ровно метрика страницы группы.
   - «Максимум P&L при МПУ ≤ …» — если важна абсолютная прибыль при ограниченном риске.
6. **Лимиты.** Потоки — сколько бэктестов Veles выполняет одновременно на вашем тарифе (у PRO — 5;
   ставьте 3–5). Пауза между созданием бэктестов — 31 с безопасно; при ответе 429 оптимизатор сам
   увеличит паузу. Лимит бэктестов ограничивает весь запуск; оценка времени показана в карточке.
7. **Старт.** Сначала прогоняется база, затем поколения: несколько кандидатов на отборочной корзине →
   лучшие на полной → новый лучший, если он лучше текущего хотя бы на минимальный порог.
8. **Результаты.** Карточка лучшего кандидата показывает изменённые параметры («было → стало») и
   метрики против базы. Для любого кандидата:
   - «Группа бэктестов» — сохраняет его бэктесты группой: откройте её и сравните с базой привычным способом;
   - «JSON» — копирует настройки;
   - «Создать бота» — создаёт **новую копию** бота с этими настройками (базовый бот не меняется).

## Сколько это стоит по времени

Один бэктест — это одна монета. Пример: полная корзина 50 монет, отборочная 10, 6 кандидатов и 2
продвижения на поколение: до 6×10 + 2×40 = 140 бэктестов за поколение (бэктесты отборочных монет
переиспользуются). При паузе 31 с это ~1,2 часа на поколение; 8 поколений — ночной прогон.
Ускоряют: готовая группа базы, меньшая полная корзина (25–30 монет), больше потоков.

## Важно

- Найденные настройки — это подгонка под историю. Перед запуском на реальные деньги проверьте лучшего
  кандидата на **другом периоде** (например, на последних 6–12 месяцах, которые не входили в оптимизацию)
  и на монетах, которых не было в корзине.
- Оптимизатор не меняет размер депозита и плечо — это решение о риске, а не о качестве настроек.
- Состояние запуска хранится в браузере (localStorage). Очистка данных браузера удалит прогресс.
