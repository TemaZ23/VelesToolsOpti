# Freelance Agent

Агент на Claude, который ведёт фриланс-заказ целиком: находит заказы, оценивает их, пишет отклики,
переписывается с клиентом, выполняет работу (Claude Agent SDK, то есть Claude Code как библиотека),
сам проверяет результат, сдаёт его и учитывает оплату. Вы управляете им из Telegram в одно нажатие.

Главное правило в коде — **агент не тратит деньги, которые не окупаются**:

- откликается только когда ожидаемая прибыль положительна:
  `P(победы) × (цена − комиссия − бюджет ИИ на выполнение) − стоимость отклика`;
- считает каждый цент API (по `usage` из каждого ответа) и проверяет лимиты **до** вызова;
- стоп-лосс: если расходы на LLM превысили заработанное больше чем на `stop_loss_usd`, новые
  отклики останавливаются до первой оплаты (уже выигранные заказы доделываются);
- у выполнения каждого заказа жёсткий потолок в долларах (`max_budget_usd` в Agent SDK) —
  не больше 25% чистой цены заказа и не больше $8 по умолчанию;
- отчёт `/stats` показывает прибыль **после** подписки и прочих фикс. расходов.

## Честно о заработке

Гарантировать доход не может ни один код: деньги приносят заказы, которые выбрал клиент. Агент
гарантирует другое — что потери ограничены вашими лимитами, а каждый отклик экономически
оправдан. Порядок цифр (команда `freelance-agent estimate`):

| | стоимость |
|---|---|
| оценка одного заказа (Claude Haiku 5.5) | ≈ $0.0005 |
| один отклик (Claude Opus 5.5) | ≈ $0.04–0.08 |
| выполнение заказа (Claude Opus 5.5, Agent SDK) | $0.5–10, всегда ≤ лимита заказа |
| поиск заказов в месяц при настройках по умолчанию | ≈ $10–25 (лимит $2/день) |

Заказ на $100 на Freelancer.com: комиссия $10, ИИ $1.5, ~20 откликов на одну победу ($1.2) →
маржа ≈ $87. Подписка $20 окупается одним таким заказом в несколько месяцев; реальная
конверсия новых аккаунтов без отзывов бывает 1–5%, агент учится на своей статистике.

Агент работает через **Claude API** (оплата по факту). Подписка Claude Pro/Max — отдельный
продукт; если вы её оплачиваете, впишите её в `budget.fixed_monthly_costs_usd`, и отчёт будет
считать окупаемость с её учётом. Рубли пересчитываются по курсу ЦБ раз в день.

## Как устроен цикл

```
FL.ru RSS ─┐                      бесплатно            Haiku 5.5            экономика
Freelancer ├─► новые заказы ─► стоп-слова, бюджет, ─► оценка: можно ли ─► EV > 0 ? ─► Opus 5.5:
RSS        ┘                   возраст, конкуренция    сделать ИИ, этично,             отклик
                                                       сложность, цена                    │
                    ┌─────────────── Telegram: ✅ / ✏️ / ❌ (или авто в режиме semi/auto) ◄─┘
                    ▼
              ставка/отклик ─► переписка (черновики ответов, требования, критерии приёмки)
                    │
              вас выбрали ─► Agent SDK в песочнице, лимит $ ─► ревью по критериям ─► доработка
                    │                                                                  │
              оплата учтена ◄── milestone / кнопка «Оплачено» ◄── сдача (zip + сообщение) ◄┘
```

## Быстрый старт на Ubuntu

```bash
git clone -b claude/freelance-agent https://github.com/TemaZ23/VelesToolsOpti.git
cd VelesToolsOpti/freelance_agent
./install.sh
```

Скрипт (Ubuntu 22.04/24.04, нужен `sudo` для пакетов) сам:

1. ставит Python, `bubblewrap` и `socat` (песочница для выполнения заказов);
2. устанавливает агента в `~/freelance-agent/venv` и команду `freelance-agent`;
3. проверяет песочницу и на Ubuntu 24.04 при необходимости добавляет профиль AppArmor,
   разрешающий именно bubblewrap (системные ограничения не снимаются);
4. запускает мастер настройки: ключ Claude API (проверяется бесплатным запросом), токен бота
   от @BotFather — вы нажимаете «Start» в боте, и мастер сам узнаёт ваш `chat_id`; профиль;
   площадки; налог самозанятого;
5. ставит службу systemd: агент работает в фоне, после перезагрузки и выхода из системы.

Обновление: `git pull && ./install.sh`. Логи: `journalctl --user -u freelance-agent -f`.
Остановить: `systemctl --user stop freelance-agent`. Настройки и данные — в `~/freelance-agent`
(`config.yaml`, `.env` с ключами, `data/`). Удалить: `systemctl --user disable --now
freelance-agent && rm -rf ~/freelance-agent ~/.config/systemd/user/freelance-agent.service`.

## Площадки и деньги из России

| площадка | оплата | поиск | отклик | переписка | сдача |
|---|---|---|---|---|---|
| **FL.ru** (RSS) — включена | российская карта / кошелёк | авто | вы вставляете готовый текст | пересылаете реплаем | zip в Telegram |
| **Pchel.net** (RSS) — включена | российские способы оплаты | авто | вы вставляете готовый текст | пересылаете реплаем | zip в Telegram |
| **Freelancer.com** (официальный API) — выключена | PayPal/Payoneer/банк — из России обычно недоступно | авто | авто или по кнопке | авто | вложение в чат |
| любой RSS | как договоритесь | авто | вручную | реплаем | вручную |

- **Как получать деньги легально.** Оформите самозанятость (приложение «Мой налог», налог 4% с
  физлиц и 6% с компаний) и выводите оплату с FL.ru/Pchel.net на свою карту. Мастер спросит про
  самозанятость, и налог будет вычитаться в отчёте о прибыли.
- **Криптовалюта.** По закону о цифровых финансовых активах (259-ФЗ) резиденты РФ по общему
  правилу не вправе принимать криптовалюту в оплату работ и услуг, поэтому агент не ищет
  «крипто-заказы». Если вы не налоговый резидент РФ и вам заплатили в USDT/USDC, учесть это
  можно так: `/paid ID 50 USDT`.
- **Без PRO на FL.ru** откликаться можно только на заказы «для всех» — их примерно пятая часть,
  агент берёт только их (`sources.flru.pro_account`).
- **Upwork, Kwork, Fiverr** не подключены: у них нет API для откликов, а боты запрещены
  правилами — за это блокируют аккаунт. FL.ru и Pchel.net агент только читает (RSS), отклик
  отправляете вы одним вставленным текстом.

### Claude API

Агенту нужен ключ Claude API: он создаётся в консоли Anthropic и оплачивается банковской
картой по факту расходов. Россия не входит в список регионов, где Anthropic предоставляет
сервис; агент рассчитан на легальный доступ к API. Отдельный workspace с лимитом расходов в
консоли — дополнительный потолок трат на стороне Anthropic.

### Другие способы установки

Вручную (любой Linux с Python 3.11+): `sudo apt-get install -y bubblewrap socat`,
`python3 -m venv venv && venv/bin/pip install .`, `venv/bin/freelance-agent setup`,
`venv/bin/freelance-agent run`.

Docker: `docker compose run --rm agent setup`, затем `docker compose up -d`. Внутри контейнера
bubblewrap нужны права на namespaces (в `docker-compose.yml` стоят `seccomp=unconfined` и
`apparmor=unconfined`); работает ли это на вашем хосте, покажет `docker compose run --rm agent check`.

### Песочница исполнителя

Исполнитель запускает код, который Claude пишет по тексту чужого заказа. Песочница ОС ограничивает
его рабочей папкой и списком доменов (pypi/npm). Без неё агент **отказывается** выполнять заказы
(`executor.allow_unsandboxed: true` — только на одноразовой машине). `freelance-agent check`
по-настоящему запускает песочницу и говорит, работает ли она.

Агент пишет от вашего имени и только правду из `profile`: не выдумывает опыт и портфолио, не
уводит оплату с площадки, на вопрос «это ИИ?» отвечает честно. Неэтичные заказы (накрутка
отзывов, курсовые, спам) отсекаются и стоп-словами, и оценкой модели.

## Команды

```
freelance-agent setup       мастер настройки (ключи, Telegram, профиль, площадки)
freelance-agent check       проверка ключа, моделей, площадок, бота, песочницы (бесплатно)
freelance-agent scan        бесплатный обзор рынка: что прошло фильтр, без LLM
freelance-agent smoke-llm   один реальный вызов оценки (< $0.01), проверка ключа и учёта
freelance-agent once        один полный цикл
freelance-agent run         работать постоянно (поиск каждые poll_interval_minutes)
freelance-agent stats       выручка, расходы, прибыль, конверсия
freelance-agent paid ID СУММА [ВАЛЮТА]   учесть оплату вручную
freelance-agent estimate --price 100 --complexity small   окупаемость заказа
```

В Telegram: `/stats`, `/jobs`, `/scan`, `/pause`, `/resume`, `/client ID текст`, `/won ID`,
`/work ID`, `/paid ID сумма [валюта]`. **Ответ реплаем на карточку** заменяет текст отклика или
ответа клиенту, пересылает агенту сообщение клиента или отправляет результат на доработку.

## Режимы автономности (`autonomy.mode`)

- `manual` (по умолчанию) — всё исходящее ждёт вашего нажатия. Начните с него.
- `semi` — на Freelancer.com ставки с оценкой ≥ `auto_bid_min_score` и ценой ≤ `auto_bid_max_usd`
  уходят сами; ответы клиентам и сдача ждут вас.
- `auto` — на Freelancer.com агент сам ставит, отвечает, принимает заказ и сдаёт результат,
  прошедший ревью. Вопросы про цену, сроки, споры и возвраты всё равно приходят вам.

## Безопасность

- Текст заказов и сообщений клиентов считается недоверенным: в промптах он изолирован тегами,
  модель проинструктирована не выполнять из него команды.
- Исполнитель: только инструменты Read/Write/Edit/Glob/Grep/Bash, без веба по умолчанию,
  `setting_sources=[]` (не читает ваши настройки Claude Code), токены Telegram и Freelancer
  вычищены из его окружения, песочница ОС обязательна (`executor.allow_unsandboxed` — только
  на одноразовой машине).
- Двойное нажатие кнопки не отправит отклик дважды; при ошибке кнопку можно нажать снова.

## Что проверено

`pytest` — 57 тестов. Среди них сквозные сценарии «заказ с FL.ru от RSS до оплаты» и
«полностью автоматический заказ на Freelancer.com», сборка агента ровно как в `run` с настоящим
клиентом Telegram против имитации Bot API (кнопки, ответы реплаем, команды, проверка HTML,
который Telegram отвергает), мастер настройки, курсы ЦБ, налог. Парсеры проверены на реальных
ответах FL.ru, Pchel.net, Freelancer.com и ЦБ (`tests/fixtures`), плюс живой запрос к площадкам
(`pytest -m live`).

Вживую на Ubuntu 24.04: `install.sh` (установка и повторный запуск как обновление), мастер
настройки, `scan`, `check` (песочница проходит), `once` с неверным ключом против настоящего API
Anthropic — агент ничего не тратит, заказы остаются в очереди, предупреждение уходит один раз.
Docker-образ собирается и запускается.

Не проверено (нужны ваши ключи и аккаунты): реальные ответы Claude (`smoke-llm` проверит за
доли цента), живой бот Telegram, отправка ставок на Freelancer.com, автозапуск через systemd
(в тестовой среде нет systemd), полный прогон исполнителя в песочнице. Начните с `check`,
`scan`, `smoke-llm` и режима `manual`.

```bash
cd freelance_agent && pip install -e ".[dev]" && pytest     # все тесты
pytest -m "not live"                                         # без сети
```
